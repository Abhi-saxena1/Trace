## Methodological limits

The current records do not support a comparative performance finding. X provides rounded display counters for many values while LinkedIn provides only comment totals here. No exact view denominator is available, so TRACE does not calculate engagement rates. Raw counts are not compared across platforms, averaged, ranked, or attributed to a launch mechanic. Existing Signal selection remains based on source-cited launch structure rather than metric magnitude.
